# 📺 SeasonVar — плагин для Lampa

Плагин для [Lampa](https://cub.red/lampa), который добавляет каталог сериалов с [seasonvar.ru](https://seasonvar.ru) и [seasonvar-enter.ru](https://www.seasonvar-enter.ru/).

## Установка

1. Открой **Lampa** → **Настройки** → **Расширения** → **Добавить плагин**
2. Вставьте URL:

```
https://sdpiter.github.io/lampaplagin/seasonvar.js
```

3. Нажмите **Установить**

## Возможности

- 🔍 **Поиск** — быстрый поиск сериалов через API seasonvar
- 📺 **Новинки** — сериалы дня
- 🔥 **Популярное** — популярные сериалы за месяц
- 📂 **Сезоны и серии** — автоматическая группировка по сезонам
- ▶️ **Прямые ссылки** — воспроизведение без торрентов
- 📋 **Плейлисты** — все серии сезона одним списком
- ⭐ **История просмотров** — отмеченные просмотренные серии
- 🌐 **CORS-прокси** — поддержка прокси для обхода ограничений
- 🏠 **Смена домена** — можно указать своё зеркало

## Использование

### Из карточки сериала
Когда вы открываете любой фильм/сериал в Lampa (из TMDB), рядом с торрент-кнопками появится кнопка **SeasonVar**. Нажмите на неё — плагин выполнит поиск по названию.

### Из главного меню
После установки плагина в главном меню Lampa появится пункт **SeasonVar**. Откроется каталог новинок.

## Настройки

**Настройки → Расширения → SeasonVar:**

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Домен | `https://seasonvar.ru` | Основной домен (можно указать seasonvar-enter.ru или зеркало) |
| CORS прокси | *(пусто)* | Адрес прокси для обхода CORS-ограничений (например, `https://corsproxy.io/?`) |

### Когда нужен CORS-прокси?

Если Lampa работает в браузере или на устройстве с политикой CORS, запросы к seasonvar.ru могут блокироваться. В этом случае укажите прокси:

- `https://corsproxy.io/?` — бесплатный публичный прокси
- Или собственный (например, на базе nginx или cloudflare workers)

При использовании прокси URL запроса передаётся как параметр: `https://corsproxy.io/?https://seasonvar.ru/autocomplete.php?query=...`

## Структура плагина

```
seasonvar.js
├── getDomain() / getCdnUrl()    # Конфигурация домена
├── getProxy() / fetchUrl()       # Поддержка CORS-прокси
├── parseSerialPage()             # Парсинг страницы сериала (secureMark, ID)
├── parsePlaylist()               # Парсинг XML-плейлиста эпизодов
├── groupBySeason()               # Группировка по сезонам
├── parseSearchResults()          # Парсинг результатов поиска
├── parseMainPage()               # Парсинг главной страницы (новинки)
├── seasonvarApi                  # API-слой: поиск, загрузка, плейлисты
├── catalogComponent              # UI: каталог сериалов / результаты поиска
└── serialComponent               # UI: сезоны → серии → воспроизведение
```

## API seasonvar.ru

| Эндпоинт | Назначение |
|----------|-----------|
| `autocomplete.php?query=...` | Поиск сериалов (JSON) |
| `/?mode=top&period=1` | Новинки дня |
| `/?mode=top&period=31` | Популярное за месяц |
| `playls2/{mark}0/trans/{id}/list.xml` | Плейлист эпизодов (XML) |
| `cdn.seasonvar.ru/oblojka/{id}.jpg` | Обложки сериалов |

## Совместимость

- **Lampa**: v1.12+
- **Платформы**: Android, Android TV, Windows, браузер
- **Языки интерфейса**: Русский, Английский, Украинский, Китайский

## Известные ограничения

- SeasonVar предоставляет прямые ссылки на видео, которые могут быть недоступны из некоторых регионов
- Сайт seasonvar.ru может быть заблокирован в вашем регионе — используйте CORS-прокси или смените домен на зеркало
- Количество результатов поиска ограничено API (до ~10 совпадений)
